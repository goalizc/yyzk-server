# 用户故事清单

> 格式：作为 [角色]，我希望 [功能]，以便 [价值]
> 每个故事附验收标准（AC）

---

## 客户侧（终端用户）

### US-01 选择产品
**作为** 遇到产品问题的用户，**我希望** 能在下拉框选择我的产品型号，**以便** 找到对应的故障方案。
- AC1：下拉框显示所有已上架产品的名称和型号
- AC2：选择后，零件下拉框自动刷新为该产品的零件列表
- AC3：未选择产品时，零件和故障下拉框禁用

### US-02 选择零件
**作为** 用户，**我希望** 能按分组选择出问题的零件，**以便** 缩小故障范围。
- AC1：零件下拉按 group_name 分组
- AC2：选择零件后，故障列表自动加载
- AC3：切换产品时，零件和故障选择重置

### US-03 浏览故障列表
**作为** 用户，**我希望** 看到当前产品+零件下的所有故障现象，**以便** 找到匹配我问题的那一条。
- AC1：列表显示故障标题和简短描述
- AC2：按 view_count 降序（常见故障排前面）
- AC3：点击卡片进入详情
- AC4：列表上方有关键词筛选框，输入后实时过滤标题与现象描述，清空恢复全量
- AC5：筛选后无结果时展示空态提示，并引导去提交工单

### US-04 查看解决方案
**作为** 用户，**我希望** 看到分步图文解决方案，**以便** 按步骤自己排查。
- AC1：步骤按数字顺序排列
- AC2：每步支持图片展示
- AC3：需专业维修的故障，顶部显示红色警告
- AC4：附件可下载

### US-05 标记已解决
**作为** 用户，**我希望** 解决后点一下"已解决"，**以便** 系统知道这个方案有效。
- AC1：点击后弹提示"感谢反馈"
- AC2：后台统计 resolved_count +1
- AC3：本次访问对应的查询日志 resolved 被置为 true（凭详情页带回的日志 ID 精确更新，不误伤他人记录）

### US-06 转工单
**作为** 用户，**我希望** 解决不了时一键提交工单，**以便** 人工客服介入。
- AC1：自动带入产品、零件、故障上下文
- AC2：填写联系方式和补充描述后提交
- AC3：提交成功后显示工单号
- AC4：后台工单列表能看到这条记录

## 后台侧（内部用户）

### US-07 登录
**作为** 售后人员，**我希望** 用账号密码登录后台，**以便** 管理知识库和工单。
- AC1：账号密码错误时提示
- AC2：登录成功进入工单列表页
- AC3：未登录访问后台页面跳登录页

### US-08 管理产品
**作为** 售后主管，**我希望** 能新增/编辑/上下架产品，**以便** 新产品上线后客户能查到。
- AC1：新增产品需要名称和型号
- AC2：型号唯一，重复报错
- AC3：下架后前台不再显示

### US-09 管理零件
**作为** 售后主管，**我希望** 按产品维护零件清单，**以便** 故障能关联到具体零件。
- AC1：零件必须归属某个产品
- AC2：支持分组和排序

### US-10 录入故障方案
**作为** 售后工程师，**我希望** 能录入故障现象、根因、分步解决方案，**以便** 客户自助解决。
- AC1：必须选择所属产品和零件
- AC2：解决步骤可以动态增删
- AC3：每步可以上传图片
- AC4：可以标记是否需要专业人员维修
- AC5：可以上传附件
- AC6：发布状态为"是"时，保存后前台立即可见（无缓存延迟）；为"否"时前台不可见

### US-11 处理工单
**作为** 售后客服，**我希望** 看到客户提交的工单并更新状态，**以便** 跟踪处理进度。
- AC1：列表显示工单号、产品、联系人（脱敏）、状态、创建时间
- AC2：能按状态、时间范围、工单号/联系方式筛选
- AC3：能查看完整上下文（产品、零件、故障、用户描述、是否需要上门）
- AC4：能把状态从 open 改成 processing 或 closed；processing 可改成 resolved 或 closed；resolved 只能改成 closed；非法流转被拒绝并提示
- AC5：每次流转自动记录操作人与时间，详情里能看到完整流转历史

### US-12 看数据统计
**作为** 售后主管，**我希望** 看到查询量、解决率、高频故障、未命中检索，**以便** 知道知识库哪里需要补。
- AC1：总览卡片数字正确；查询次数/解决率/工单总数随时间筛选变化，"待处理"为当前积压不变化（卡片有标注）
- AC2：TOP 10 故障按所选时间窗内的查看次数排序
- AC3：未命中检索词列表显示用户查了但没结果的词，按频次排序；用户没输关键词的记录单独归组
- AC4：切换近 7 天 / 近 30 天 / 全部时，三个统计区块同步刷新
- AC5：解决率口径与 PRD §4 一致（按查询日志计算，非历史累计）

### US-13 修改密码
**作为** 售后主管，**我希望** 能自己修改后台密码，**以便** 交付后第一时间替换默认密码，不必找运维。
- AC1：顶栏用户菜单能打开"修改密码"
- AC2：原密码错误时提示且不修改
- AC3：新密码少于 8 位、与原密码相同、或两次输入不一致时拦截
- AC4：修改成功后仍保持登录状态

## 故事优先级与排期
| 故事 | 优先级 | 排期 |
|---|---|---|
| US-01 ~ US-06（客户侧） | P0 | W1-W2 |
| US-07（登录） | P0 | W2 D1 |
| US-08 ~ US-10（知识库 CRUD） | P0 | W2 |
| US-11（工单管理） | P0 | W2 |
| US-12（统计看板） | P1 | W2 D4-W3 D1 |
| US-13（修改密码） | P0 | W2 D1（与登录同批） |

> 共 13 个故事。US-13 虽小，但它是"默认密码必须修改"这条验收项的唯一落地手段，不能推到二期。
