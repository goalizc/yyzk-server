# 人员分工与责任矩阵（RACI）

> R = 负责执行（Responsible）
> A = 最终问责（Accountable）
> C = 被咨询（Consulted）
> I = 被告知（Informed）

## 角色定义
| 代号 | 角色 | 说明 |
|---|---|---|
| PM | 项目负责人 | 排期、风险、进度跟踪 |
| BE | 后端开发 | FastAPI、DB、部署 |
| FE | 前端开发 | Vue3 客户页 + 后台 |
| QA | 测试 | 用例执行 |
| OPS | 运维 | 服务器、备份 |
| OPS-K | 售后知识运营 | 故障数据整理录入 |
| BOSS | 项目发起人 | 审批 |

## 最小人力配置
- **必须全职**：BE × 1、FE × 1
- **必须投入时间**：OPS-K × 0.5 人（售后团队出 1 人，每周约 2 天整理数据）
- **可兼任**：PM（BE 兼任）、QA（FE 兼任）、OPS（BE 兼任）

## 沟通机制
| 机制 | 频率 | 参与人 | 内容 |
|---|---|---|---|
| 站会 | 每天 10:00，15 分钟 | BE、FE、PM | 昨天做了什么、今天做什么、阻塞 |
| 周会 | 每周五下午 | 全员 | 进度同步、风险、下周计划 |
| 需求变更 | 随时 | PM + BOSS | 变更必须走变更单，评估影响后排期 |
| 内测反馈 | D-03 起 | 售后团队 | 用企业微信群提 bug |
