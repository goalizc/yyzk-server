# 故障知识库阅读抽屉 设计稿

**日期：** 2026-10-22
**状态：** 已确认，待实施

## 1. 背景与目标

后台「故障知识库」列表当前点击行直接进入编辑表单。一线客服只有 `fault:read`，进入后看到的是一张全部禁用的表单，阅读体验与「查方案答复客户」的目的不匹配。

目标：点行打开抽屉，用与客户侧一致的图文排版阅读方案；需要修改的人再从抽屉或行内进入编辑页。

## 2. 范围

**做：**

- 列表行点击 → 阅读抽屉（所有角色）
- 抽屉复用客户侧展示结构（标题、状态、元信息、风险提示、现象/原因/工具、分步图文、附件）
- 「复制方案文本」：文字 + 已发布方案的客户页链接
- 有 `fault:write` 时保留行内与抽屉内「编辑」入口
- 窄屏适配

**不做：**

- 不新增后端接口，数据用现有 `GET /api/admin/faults/{id}`
- 不做图片复制/导出
- 不改客户侧页面行为（反馈、提交工单保持原样）
- 不做工单与知识库的关联跳转
- 不做未发布方案的对外分享

## 3. 交互

| 角色 | 行点击 | 行内操作 | 抽屉底部 |
|---|---|---|---|
| 超管 / 主管（`fault:write`） | 打开阅读抽屉 | 编辑、删除 | 编辑、复制方案文本、打开客户页（仅已发布）、关闭 |
| 客服 / 审计（仅 `fault:read`） | 打开阅读抽屉 | 无 | 复制方案文本、打开客户页（仅已发布）、关闭 |

- 抽屉从右侧滑出，桌面宽度 `720px`，窄屏（≤768px）`100%`
- 抽屉打开时请求详情；加载中显示骨架屏；失败显示错误与「重试」
- 抽屉元信息显示「产品 / 零件 · 更新时间 · 查看 N 次 · 解决 N 次」
- 「编辑」点击后关闭抽屉并跳转 `/admin/faults/edit/{id}`
- 「打开客户页」新窗口打开 `/faults/{id}`，仅在 `is_published=true` 时显示

## 4. 组件划分

| 文件 | 职责 |
|---|---|
| `frontend/src/components/FaultSolutionView.vue` | 纯展示：标题、状态标签、元信息、风险提示、描述、步骤图、附件；不请求数据、不含客户侧反馈动作 |
| `frontend/src/views/admin/faults/FaultReaderDrawer.vue` | 抽屉容器：加载详情、错误/骨架、底部操作、复制与跳转 |
| `frontend/src/utils/faultCopy.js` | 纯函数 `buildFaultCopyText(fault, origin)`，便于单测 |
| `frontend/src/utils/clipboard.js` | `copyText(text)`：优先 Clipboard API，失败时用 textarea + `execCommand` 兜底（HTTP 内网环境必需） |
| `frontend/src/views/public/FaultDetail.vue` | 改为复用 `FaultSolutionView`，保留反馈与提交工单卡片 |

`FaultSolutionView` props：

```text
fault: object            必填，FaultAdminDetail 或公开 FaultDetail
showStats: boolean       默认 false；客户页显示查看/解决次数
showStatus: boolean      默认 false；后台抽屉显示已发布/未发布、需专业标签
```

## 5. 复制文本格式

```
【开机无反应】
产品：扫地机器人 X1 / 电池组

现象：插电后指示灯不亮
可能原因：电池过放保护
所需工具：十字螺丝刀

处理步骤：
1. 检查电源适配器指示灯是否亮起
2. 长按电源键 10 秒
   [含示意图]

完整图文方案：http://192.168.1.2/faults/123
```

规则：

1. 标题、产品/零件必填；现象、原因、工具为空则整行省略
2. `needs_professional=true` 时在正文前加：
   `⚠️ 该故障建议由专业人员处理，请勿自行拆机`
3. 步骤按 `step` 升序；有 `image_url` 的步骤后追加一行 `   [含示意图]`
4. 已发布：末尾 `完整图文方案：{origin}/faults/{id}`
5. 未发布：不附链接，末尾改为 `（该方案尚未发布，配图请在系统内查看）`
6. 不复制查看次数、解决次数、创建人等内部字段
7. 链接 origin 取 `import.meta.env.VITE_PUBLIC_BASE_URL || window.location.origin`；本次不新增构建配置，仅保留该读取逻辑

## 6. 错误与边界

- 详情 404：抽屉内提示「方案不存在或已删除」，可关闭
- 详情请求失败：显示错误文案与重试
- 复制失败：提示「复制失败，请手动选择文本」
- 方案已发布但客户页 404（并发下架）：新窗口由客户页自行提示，抽屉不做额外处理
- 无 `fault:read`：路由守卫已拦截，列表不可达；抽屉不单独处理

## 9. 验收标准

1. 任意角色点故障行打开抽屉，不再进入编辑页
2. 抽屉内容与客户侧一致，图片可放大、附件可打开
3. 有 `fault:write` 时行内与抽屉内都有「编辑」
4. 已发布方案复制文本末尾含客户页链接；未发布方案无链接且有提示
5. 图片步骤在文本中标注 `[含示意图]`
6. HTTP 内网环境下复制按钮可用
7. 窄屏抽屉全宽，无横向溢出
