## 2. 六项需求冲突的裁决（决策日志）

> 这 6 项原本标注"待裁决"。为了产出可执行的 v1.1，我按工程合理性与验收可行性做了选择。
> **如果你不同意其中任何一项，告诉我编号即可回滚** —— 每项的改动面已在表中列出。

### D-01（对应 C-01）未命中词怎么产生 → **选 B：加选填关键词框**

- **决定**：P-01 故障列表上方增加选填关键词框（≤50 字），仅在当前产品+零件结果内做包含匹配；无结果时前端上报 `POST /api/query-logs`。
- **为什么不是 A（空结果补日志）**：`raw_query` 会退化成"产品名/零件名"，看板叫"未命中检索词"就是撒谎。
- **为什么不是 C（砍功能）**：章程验收标准明确写了"后台能看到未命中词"，砍掉要改合同级指标；而加一个输入框只花 0.5 人天。
- **代价**：+0.5 人天前端（C-10）、+0.5 人天后端（B-06 扩展）、新增 1 个接口、1 张表字段语义变化。
- **改动面**：PRD F-3/F-11、页面 P-01/P-17、API §4、US-03、WBS C-10、用例 TC-12/13/16/34。

### D-02（对应 C-02）解决率口径 → **按查询日志计算，3 个月 ≥30%**

- **决定**：`resolve_rate = 窗口内 resolved=true 的 query_logs 条数 ÷ 窗口内 fault_id 非空的 query_logs 条数`。3 个月目标 30%，首月 20% 标注为观察值。
- **理由**：`faults.resolved_count / view_count` 是历史累计，与"近 7 天/30 天"筛选天然矛盾；必须用逐条日志才能联动。
- **代价**：无额外工作量，但需要 `query_logs.resolved` 可靠（依赖 D-03）。
- **改动面**：PRD §4 指标口径、API §6、路线图成功指标、TC-31。

### D-03（对应 C-03）反馈如何定位日志 → **详情返回 `query_log_id`，反馈必须回传**

- **决定**：`GET /api/faults/{id}` 返回本次访问的日志 ID；`POST /feedback` 必须带 `query_log_id`，不匹配返回 400 `QUERY_LOG_MISMATCH`。
- **理由**：这是唯一能在并发下保证正确的做法。按 IP + 时间窗兜底在 NAT 环境必串号。
- **代价**：前端多存一个字段（页面 P-02 已写明）；接口不兼容旧调用方（当前无存量，成本为零）。
- **改动面**：API §4、页面 P-02、US-05、TC-08/45。

### D-04（对应 C-04）操作人记在哪 → **新建 `ticket_status_logs` 表**

- **决定**：每次状态变更写一条日志（from/to/operator/remark/time），`operator_id` 从 token 取，前端不可指定。
- **理由**：只存最终状态无法复盘"谁把工单关了"。表很小，成本几乎为零。
- **代价**：+0.5 人天后端、+0.5 人天前端（抽屉历史区）。
- **改动面**：schema 第 7 表、API §5 PUT 与详情 history、页面 P-12、US-11 AC5、TC-30/36。

### D-05（对应 C-05）产品删除策略 → **外键 RESTRICT + 应用层 409**

- **决定**：`parts.product_id` 与 `faults.product_id/part_id` 全部 `ON DELETE RESTRICT`；删除前查引用，有则 409 `DELETE_BLOCKED` 并给出条数。
- **理由**：删除是低频高危操作，静默级联删除零件和故障是数据事故，不是"便利"。
- **代价**：运维清理脏数据时需先迁后删（正确行为）。
- **改动面**：schema 外键、API DELETE、页面 P-13（`fault_count` 提示）、TC-35。

### D-06（对应 C-06）一期含不含用户管理 → **不含管理，但必须能改密**

- **决定**：一期不做账号增删改与角色配置（写入章程"不做什么"）；`users` 表由 `init_admin.py` 与运维 SQL 维护；新增 `PUT /api/auth/password` 与顶栏改密弹窗。
- **理由**：验收表要求"默认密码已修改"，没有改密入口就只能手工 SQL，不可接受；而多角色权限是路线图三期 3.5 的内容。
- **代价**：+0.5 人天后端、+0.5 人天前端。
- **改动面**：PRD §2/§5/F-12、章程范围、API §1、页面 P-11、US-13、WBS B-02/C-11、TC-37/38。
