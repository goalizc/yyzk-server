## 2. Major（已修）

### R1 ElMessage 是否真的进了构建产物（取证后排险）

按需引入改造后，`grep "el-message" dist/assets/*.js` **搜不到任何结果**。如果 AutoImport
没有注入 ElMessage，所有"已解决/提交太频繁/复制成功"的提示会在运行时抛 `ReferenceError`，
页面交互全挂，且构建不报错。

取证过程：
1. 各页面文案（"已复制工单号"等）都在产物中 → 调用点在；
2. `ElMessage` 标识符出现在共享 chunk `index-71WOaSMH.js`（12.5 kB）→ message 组件被
   提为共享 chunk；
3. `el-message` 字面量搜不到是因为类名由 namespace 工具在运行时拼接（`el-` + `message`）；
4. 最直接的证据是组件测试：`TicketNew.spec.js` 的 429 用例断言 DOM 里出现
   `.el-message--warning`，通过——AutoImport 在构建期注入成功。

**结论**：非缺陷，但暴露了"构建不报错 ≠ 运行时可用"的验证缺口，组件测试正是兜底。
